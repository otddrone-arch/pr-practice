# pr-practice

A tiny practice repository for learning the GitHub pull request workflow.

## What this is

This repo exists so I can practice: making a change on a branch, pushing it,
and opening a pull request on GitHub.

## Usage

There's nothing to install or run here yet — it's just a starting point.

## Workflow

The steps this repo is meant to practice:

1. Create a branch for your change.
2. Commit the change with a clear message.
3. Push the branch to GitHub.
4. Open a pull request and merge it.
